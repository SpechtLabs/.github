## Projects

Some of the repositories we work on:

- [sigil](https://github.com/SpechtLabs/sigil): a small, statically typed policy language for Go hosts.
- [tka](https://github.com/SpechtLabs/tka): zero-friction Kubernetes access using Tailscale and ephemeral service accounts.
- [kush](https://github.com/SpechtLabs/kush): ephemeral, isolated kube-context subshells, with a private, throwaway kubeconfig per shell.
- [telegram-tui](https://github.com/SpechtLabs/telegram-tui): a keyboard-driven terminal client for Telegram.
- [golint-sl](https://github.com/SpechtLabs/golint-sl): SpechtLabs best practices for writing good Go code, as linters.
- [humane-errors-go](https://github.com/SpechtLabs/humane-errors-go): errors that make your users' lives easier, not harder.
- [StaticPages](https://github.com/SpechtLabs/StaticPages): a server for hosting static pages, with preview URLs.

sigil, kush and telegram-tui (`tgt`) install with Homebrew from [our tap](https://github.com/SpechtLabs/homebrew-tap).
